# 🎰 Python Slots Machine Game

A **Python-based command-line slots machine game** where players can **place bets, spin the reels, and win prizes** based on matching symbols. Built using **randomized slot mechanics**, **betting strategy**, and a **simple payout system**.

---

## 📌 Features
✅ **Bet on up to 3 lines**  
✅ **Customizable betting amount**  
✅ **Randomized slot spins with fair probability**  
✅ **Real-time balance tracking**  
✅ **Winning combinations & payouts**  

---

## 🎮 How to Play

1️⃣ **Deposit Money** → Enter the amount you'd like to start with.  
2️⃣ **Place Your Bet** → Choose how many lines (1-3) to bet on and the bet amount per line.  
3️⃣ **Spin the Slots** → The game randomly generates slot results.  
4️⃣ **Win or Lose** → If symbols match on your selected lines, you win a payout!  
5️⃣ **Keep Playing** → Continue until you run out of balance or quit the game.  

---

## 📂 Project Structure

- `slots.py` → Main script containing game logic  
- Uses **Python’s random module** for randomness  

---

## 🛠️ Installation & Setup

### 🔧 Prerequisites
Ensure you have **Python 3.x** installed.

### 🚀 Running the Game
```sh
python slots.py
```
